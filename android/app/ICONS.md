# App icon

`res/drawable-nodpi/ic_launcher_foreground.png` and `runelite_logo.png` are made from the
unmodified RuneLite logo in the RuneLite launcher repository (`osx/runelite.icns`, BSD
2-Clause License, Copyright (c) 2016, Adam). The only changes are resizing and padding
for Android's adaptive icon format.

The logo is RuneLite's branding. This is an unofficial port for personal use; don't
publish it under RuneLite's name or logo without the RuneLite team's permission.
